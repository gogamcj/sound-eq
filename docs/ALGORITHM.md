# DSP 분석 및 EQ 추천 알고리즘

초기 버전은 **설명할 수 있는 규칙 기반**입니다. 모든 추천에는 근거 문장, 신뢰도, 근거 충분 여부, 청음 확인 필요 여부가 붙습니다.

## 1. 처리 구조 (스레드 분리)

```
PortAudio 콜백 ──(블록 복사 + 큐 put_nowait만)──▶ 큐 ──▶ 분석 스레드(DspAnalyzer) ──▶ 스냅샷
                                                                         │
GUI 타이머(15fps) ◀──────────── snapshot() 읽기 ─────────────────────────┘
작업 스레드: 믹서 조회/쓰기, 추천 계산          자동 보정 스레드: 1초 주기 판단
```

* 콜백에서는 FFT, 네트워크, 파일, GUI 작업을 하지 않습니다. 큐가 가득 차면 블록을 버리고 '드롭' 수를 셉니다. PortAudio 상태 플래그는 '오류'로 셉니다.
* 지연은 단계별로 따로 기록합니다: 오디오 입력(ADC → 콜백), 분석(수신 → 분석 완료), 화면 갱신, 믹서 제어(파라미터당 왕복). 결과는 화면 오른쪽 아래에 나옵니다.
* 성능: 48채널, FFT 4096, 홉 1024 기준으로 분석이 실시간보다 약 5.8배 빠릅니다 (리눅스 테스트 머신 측정, 노트북 실측 필요).

## 2. 분석 항목

| 항목 | 방법 |
|---|---|
| RMS / 피크 / 피크 홀드 | 블록 단위. 피크 홀드는 초당 20 dB씩 떨어짐 |
| 클리핑 | \|x\| ≥ 0.999 (USB로 받은 디지털 신호 기준. 프리앰프 아날로그 클리핑은 직접 볼 수 없음) |
| 무음 / 신호 부족 | RMS < -60 / -45 dBFS (설정 가능) |
| 스펙트럼 | STFT (창: hann/hamming/blackmanharris, FFT 2048–16384, 홉 설정 가능), 파서발 보정 |
| 로그 대역 | 1/24 옥타브 (20 Hz–20 kHz) |
| 장기 평균 | 시간상수 12초 EMA. **어택 프레임(+6 dB 급상승)과 신호 부족 프레임은 제외** |
| 지속성 | 대역별로 "1/3 옥타브 주변보다 3 dB 이상 돌출"된 프레임의 비율 (EMA) |
| 기본음 | 하모닉 곱 스펙트럼(HPS)으로 f0와 신뢰도 추정. 음정 분포(IQR, 반음 단위) |
| 저역/중역/고역 상태 | 추세선 대비 영역 평균 (아래 3절) |

## 3. 추천 규칙

입력 데이터는 장기 평균 스펙트럼입니다. `pre_eq` 탭이면 여기에 현재 EQ 커브를 더합니다. 이것을 1/3 옥타브로 파워 평활합니다.

1. **게이트**: 무음, 클리핑, 신호 부족, 분석 시간 8초 미만, 현재 EQ를 읽지 못한 경우에는 추천하지 않습니다 (덮어쓰기 방지).
2. **추세선**: 잡음 바닥(최대치 -45 dB 이하)을 뺀 뒤 log-주파수 2차 곡선을 맞추고, 4 dB 넘게 튀는 부분을 빼서 다시 맞춥니다. 이 곡선을 그 악기의 "자연스러운 외형"으로 봅니다.
3. **영역 과잉** (프로필의 regions): 영역 평균 잔차가 허용치를 넘을 때만 그 영역의 최대점에 감쇠를 추천합니다. 양은 `-(초과분×0.7+1)`이고 프로필 최대 감쇠로 제한합니다. **측정한 기본음이 그 영역 안에 있으면 허용치를 +3 dB 올리고 '청음 확인'으로 표시합니다.**
4. **저주파 잡음 → HPF**: 프로필 HPF의 0.8배 아래 에너지가 주 대역보다 -20 dB 이상 크면 HPF를 추천합니다. 연주 음정(f0)이 그 근처까지 내려가면 추천하지 않습니다. HPF는 자동 모드에서 바꾸지 않습니다.
5. **지속 공진**: 장기 평균에서 1/6 옥타브 평활과 1 옥타브 평활의 차이가 3.5 dB를 넘고, 지속성이 50%를 넘거나 음정이 3반음 이상 바뀌면서도 계속 남아 있는 돌출입니다. 음정이 고정된 상태(IQR < 2반음)에서 f0의 정수배 ±1반음에 해당하면 **악기의 기본음이나 배음으로 보고 감쇠하지 않습니다.** Q는 반치폭으로 추정합니다 (2–8).
6. **존재감 부족** (보컬): 2–5 kHz 잔차가 -5 dB보다 낮을 때만 +2 dB 이내로 부스트합니다. 항상 '청음 확인'으로 표시하고, 자동 모드에서는 금지(기본값)입니다.
7. **하울링 의심**: 아래 4절. 의심도가 0.8 이상이고 배음 관계가 없을 때만 노치를 추천합니다 (Q 8, -3~-6 dB, 채널당 최대 2개).
8. **밴드 배정 (기존 EQ 보존)**: 같은 주파수(1/3 옥타브 안)를 이미 쓰는 밴드가 있으면 **게인만** 더하고, 그 밴드의 주파수와 Q는 그대로 둡니다. 아니면 게인이 0인 빈 밴드를 씁니다. 빈 밴드가 없으면 추천하지 않습니다.
9. **신뢰도** = 문제 강도 × 데이터 양(30초 기준) × 악기 확정 여부(확정 1.0 / 미확정 0.6 / 미지정 0.4). 0.5 이상이면 '근거 충분'입니다.
10. 확실한 문제가 없으면 `no_issue`("EQ 변경 권장 없음")를 표시합니다.

악기 프로필 21종의 수치는 경험적인 출발점이며 `config/instrument_overrides.json`으로 조정할 수 있습니다. **실제 공연 녹음으로 조정해야 합니다** (FEATURE_STATUS 참고).

## 4. 하울링 의심도

단일 FFT 피크로 판단하지 않고 다음을 함께 봅니다.

* 돌출: 1/3 옥타브 주변보다 10 dB 이상
* 지속: 같은 대역(±1)에서 0.7초 이상 머무름. 사라지면 3배 속도로 감소
* 추세: 레벨이 떨어지는 중이면 ×0.7
* 배음 관계: 현재 f0의 정수배(±10%)이면서 이웃 배음(f±f0)도 돌출돼 있는 비율이 50%를 넘으면 ×0.4 (순음 하울링은 이웃 배음이 없음)

의심도 0.5 이상이면 경고, 0.8 이상이면 '높음'이고 노치 후보가 됩니다. 시뮬레이션에서는 2.52 kHz 순음을 1.00으로, 악기 배음들을 ≤0.31로 판정했습니다. 실제 공간의 하울링 데이터로는 아직 검증하지 않았습니다.

## 5. 적용 후 확인

* 모든 쓰기는 재조회로 확인합니다. 값이 다르면 '적용 실패(불일치)'입니다.
* 자동 적용 뒤에는 조정 간격의 75% 시점에 같은 종류의 문제 지표를 다시 계산합니다. 1 dB 이상 나빠졌거나 하울링 의심이 새로 생기면 그 채널의 자동 보정을 정지합니다.
