# LAN 연결 및 제어 설정

1. 노트북과 WING COMPACT를 유선 Ethernet으로 연결합니다 (직결 또는 스위치).
2. WING의 네트워크 설정에서 IP를 확인합니다. 노트북의 유선 어댑터를 같은 서브넷의 고정 IP로 설정합니다. 예: WING 192.168.1.71 / 노트북 192.168.1.50, 마스크 255.255.255.0.
3. Windows 방화벽이 Python(또는 WingAutoEQ.exe)의 **UDP 송수신**을 허용하는지 확인합니다. 처음 실행할 때 나오는 허용 대화상자에서 '개인 네트워크'를 허용합니다.
4. 연결을 확인합니다.
   * `python -m tools.verify_connection --discover`는 `WING?`를 UDP 2222로 브로드캐스트합니다. 응답이 없으면 브로드캐스트가 막혀 있을 수 있으므로 IP를 직접 입력합니다.
   * `python -m tools.verify_connection --ip <WING IP> --ch 1`은 `/?` 응답, 채널 수, ch1 이름, EQ와 필터 값, 범위 질의 결과를 보여 줍니다.
5. 프로그램에서는 '연결 > 연결 및 설정 > 믹서 (LAN)'에 IP를 넣고 '연결 테스트'를 누른 뒤 확인을 누릅니다.

## 통신 동작

| 항목 | 값 |
|---|---|
| 프로토콜 | OSC over UDP, 포트 2223 (문서 근거: [PROTOCOL_NOTES.md](PROTOCOL_NOTES.md)) |
| 요청 타임아웃 | 0.5초 (설정 가능), 재시도 2회 |
| 상태 확인 | 0.5초마다 `/?`를 재시도 없이 보냄. 2회 연속 실패하면 '통신 단절' |
| 단절 시 | 자동 보정 즉시 중지. 3초 간격으로 재연결을 시도하고, 다시 연결돼도 자동 보정은 꺼진 채로 둠 (사용자가 다시 켜야 함) |
| 쓰기 | 사전 검증 → 현재값 재조회 → 바뀐 값만 전송 → 50 ms 후 재조회 → 비교 |

WING은 OSC 구독을 한 번에 하나만 허용합니다. 이 프로그램은 구독을 쓰지 않고 필요할 때 조회(폴링)합니다. 그래서 다른 원격 앱의 구독을 빼앗지 않습니다. 다른 원격 앱과 동시에 쓰는 경우의 동작은 아직 검증하지 않았습니다.
