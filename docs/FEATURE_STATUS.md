# 구현 현황

표기: ✅ 구현됨 + 시뮬레이터/가상 입력 테스트 통과 · 🟡 구현됐지만 실장비 의존 부분이 미검증 · ❌ 미구현

**실장비 검증은 아직 0건입니다.** 그래서 하드웨어와 맞닿는 항목은 모두 🟡입니다.

## 하드웨어 연결
| 기능 | 상태 |
|---|---|
| 오디오 장치 검색, WING 후보, 샘플레이트·최대 채널 확인 | 🟡 (가짜 sounddevice로 테스트) |
| 다채널 USB 수신 스트림, 드롭아웃 집계, 워치독 재연결 | 🟡 |
| USB↔믹서 매핑 설정과 검증 | ✅ |
| OSC 클라이언트 (타임아웃, 재시도), 디스커버리 | 🟡 (문서 형식 기반, 시뮬레이터 통과) |
| 채널 이름과 번호, EQ, 필터, EQ ON 읽기 | 🟡 (경로가 실장비에서 미확인) |
| 장비 범위 질의, 사전 검증 | 🟡 (leaf `,s ?` 지원 여부 미확인) |
| EQ 쓰기 + 재조회 확인, 동일값 미전송, 외부 변경 감지 | 🟡 |
| 상태 확인, 단절 감지, 자동 재연결, 단절 시 자동 중지 | 🟡 |
| 네이티브 TCP 프로토콜 어댑터 | ❌ (해당 문서 절을 확보하지 못함. OSC로 충분한지 실장비에서 판단) |

## 분석, 추천
| 기능 | 상태 |
|---|---|
| RMS, 피크, 클리핑, 무음, FFT(창, 크기, 홉 설정), 로그 대역, 장기 평균, 어택 구분, f0 | ✅ |
| 단계별 지연 측정 (입력, 분석, GUI, 믹서) | ✅ |
| 악기 프로필 21종 | ✅ (수치는 휴리스틱 → 실제 녹음으로 조정 필요) |
| 규칙 기반 추천 (근거, 신뢰도, 근거 충분, 청음 확인, 현재와 추천 비교, 예상 커브) | ✅ (합성 신호 기준. 실제 악기에서의 타당성은 미검증) |
| 보조 악기 분류 | ✅ (단순 규칙, 상한 0.6. 정확도는 낮은 편) |
| 하울링 의심도와 노치 추천 | ✅ (합성 순음 기준) |
| EQ 커브 표시 | 🟡 (일반 필터 근사. WING 내부 커브와 다를 수 있음) |
| 킥과 베이스 마스킹처럼 두 채널을 함께 보는 분석 | ❌ (채널별 분석만. '청음 확인' 메모로만 안내) |
| AI 기반 분류 | ❌ (명세상 이후 단계) |
| librosa 사용 | ❌ (불필요해서 사용하지 않음) |

## 적용, 안전, 기록
| 기능 | 상태 |
|---|---|
| 모드 A, B, C와 모든 안전 게이트 (SAFETY.md) | ✅ |
| 사용자 승인 적용, 거부, 이력, 복구 (사용자 변경 보존) | ✅ |
| 제한적 자동 보정 (변경량, 빈도, 누적, 1밴드, 부스트 금지, 악화 감지) | ✅ |
| 자동 노치 (옵션, 기본 꺼짐) | ✅ |
| SQLite: 프로필, 매핑, 변경 전후, 승인과 거부, 자동 적용, 이벤트와 오류, 분석 요약 테이블 | ✅ (분석 요약은 테이블과 API만 있고 주기적 저장은 아직 연결 안 함) |

## GUI, 배포
| 기능 | 상태 |
|---|---|
| 메인 화면 (상태 칩, 미터, 채널 목록, 모드, 전체 정지), 채널 상세 (스펙트럼, 커브, 비교표, 적용·거부·복구), 설정 | ✅ (offscreen 실행과 화면 캡처 확인. Windows 실제 화면은 미확인) |

| 실시간 장시간 실행 | 🟡 (가속 120초×48ch만 테스트. 4시간 이상 실행은 실장비로 필요) |
