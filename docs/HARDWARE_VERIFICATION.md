# 검증 기록: 시뮬레이터 결과와 실제 장비 결과 분리

## A. 시뮬레이터 / 가상 입력 검증 (완료)

환경: Linux 컨테이너, Python 3.13, numpy 2.x / scipy 1.18 / PySide6 6.12 (offscreen). 실행일 2026-10-28.
대상: `simulator/fake_wing.py` (문서의 응답 형식을 흉내 낸 UDP 서버, **범위와 초기값은 임의**)와 합성 오디오.

| 항목 | 결과 |
|---|---|
| `pytest` 전체 (51개) | 전부 통과 |
| `verify_connection --simulate --write-test 3 --confirm-write` | 응답, 채널 수 40, EQ와 필터 29개 읽기, 범위 19개, 쓰기 → 재조회 → 복구 PASS |
| 48채널 분석 성능 | 실시간 대비 약 5.8배 (10초 분량을 1.7초에 처리) |
| GUI | 시뮬레이션 모드에서 실행하고 화면 캡처까지 확인 (상태 칩, 미터, 스펙트럼, 추천 비교표) |
| 하울링 시뮬레이션 | 2.52 kHz 순음은 의심도 1.00, 악기 배음은 ≤ 0.31 |

**이 결과는 실제 WING COMPACT, 실제 USB 드라이버, 실제 악기 신호에 대한 검증이 아닙니다.**
